# Voice Iteration Guide

## Phase 1 — Lock the Core Identity
Generate 3–5 short samples of the same sentence while only changing minor parameters. Choose the version that best matches your target.

## Phase 2 — Stress Test
Try the locked voice on:
- Long narration paragraphs
- Conversational back-and-forth
- Technical terms / numbers
- Emotional range (calm → slightly more energy)

## Phase 3 — Save the Locked Version
Once happy, update the profile JSON and the `grok_prompt` field with the exact successful description.

## Useful Adjustment Phrases
- “Slightly lower pitch while keeping the same warmth”
- “Reduce speaking rate by ~15%”
- “Add a subtle smile in the delivery without becoming cheerful”
- “Make consonants clearer / crisper”
- “Reduce breathiness”
- “Keep the Canadian soft accent but increase clarity”
